# Changelog

## 1.0.0

First release.

- F5 opens the game's built-in save menu anywhere. The key is configurable.
- Loading a hotkey save skips the phone pose, conversation and hang-up animation, including behind the main menu.
- The hotkey only works in calm player states (standing, walking, sprinting, turning, crouching) and with no menu open.
- Hotkey saves set `PV_PlayerHasSaved`, just like payphone saves.
- Optional `FreePhoneCalls` setting (off by default) removes the coin requirement on payphones.
